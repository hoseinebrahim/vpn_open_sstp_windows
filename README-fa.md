# Open-SSTP Windows — پیش‌نمایش با فایل‌های Wintun

این پروژه یک رابط آزمایشی Windows Forms برای انتقال پروژهٔ Open-SSTP اندروید به ویندوز است. سورس اصلی اندروید در پوشهٔ `reference/` صرفاً برای مرجع نگهداری شده است.

## وضعیت
- رابط ویندوز و نمودار نمونه: موجود
- فایل‌های رسمی Wintun برای x64/x86/ARM64: اضافه شده
- لودر اولیهٔ Wintun API: اضافه شده (`WintunNative.cs`)
- موتور SSTP/PPP ویندوزی، تونل IP، مسیریابی و DNS: **هنوز تکمیل نشده**
- اتصال VPN واقعی: **در این نسخه کار نمی‌کند**
- نمودار فعلی: آمار کلی شبکهٔ سیستم است، نه سرعت اختصاصی VPN

جزئیات ادغام Wintun و مراحل باقی‌مانده: `WINTUN-INTEGRATION-fa.md`.

## ساخت
روی ویندوز با .NET 8 SDK:
```powershell
dotnet build -c Release -p:PlatformTarget=x64
```
این دستور پروژهٔ WinForms را می‌سازد؛ به معنی آماده بودن تونل VPN نیست.
